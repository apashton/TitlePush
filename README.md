# Title Push

A football management game in your browser. Start on a roped-off park pitch in the County Sunday League,
ten tiers from the top, and push your club, and its ground, all the way to the top of the table.

**Play: https://apashton.github.io/TitlePush/**

This repository is the public home of the playtest: the website (`index.html`) and the game itself
(`play.html`, one self-contained file that runs offline and saves in your browser). The game's source is
developed separately; each playtest build is published here.

## Feedback

Found a bug, or have an idea? [Open an issue](https://github.com/apashton/TitlePush/issues) with what
happened. In the game, Club → Save → "Export playtest timings" saves how long you spent on each screen,
which helps a lot.
