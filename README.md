# Title Push

A football management game in your browser. Start on a roped-off park pitch in the County Sunday League,
ten tiers from the top, and push your club, and its ground, all the way to the top of the table.

**Play: https://apashton.github.io/TitlePush/**

**On a phone:** put it on your home screen and it opens like an app, always on the newest playtest. On
Android, tap Install on the game's title screen (or use the browser's menu); on an iPhone or iPad, tap
Share, then Add to Home Screen.

**What's new:** [version history](https://apashton.github.io/TitlePush/versions.html) (also
[`CHANGELOG.md`](CHANGELOG.md) and [`changelog.json`](changelog.json)). Each playtest is tagged, and
newer ones have a [release](https://github.com/apashton/TitlePush/releases) with the game attached.

This repository is the public home of the playtest: the website (`index.html`), the game itself
(`play.html`, one self-contained file that runs offline and saves in your browser), and its version
history (`versions.html`). The game's source is developed separately; each playtest build is published
here.

## Feedback

Found a bug, or have an idea? [Open an issue](https://github.com/apashton/TitlePush/issues) with what
happened. In the game, Club → Save → "Export playtest timings" saves how long you spent on each screen,
which helps a lot.
